# SPARK 2026 video working folder

Media files here are **not committed to git** (they are large); only this README is. Keep a backup copy on Google Drive.

| Folder | What goes in it | Who adds it |
|---|---|---|
| `video/raw/` | Scene 1 face clip (`face_intro_take1.mp4`) and voice-over takes (`vo_03_take1.m4a`, ...) | Danish |
| `video/footage/` | Stock clips from Pexels / Pixabay (each listed in `docs/spark/FOOTAGE.md`) | Claude, after Danish approves the shortlist |
| `video/screens/` | Scripted 1080p screen recordings of the app | Claude |
| `video/motion/` | Motion-graphics clips (title, cards, end card) | Claude |
| `video/render/` | Rough cut and the final export | Claude, then Danish |

Script: [`docs/spark/VOICEOVER_SCRIPT.md`](../docs/spark/VOICEOVER_SCRIPT.md) (lines to read) and [`docs/spark/VIDEO_PLAN.md`](../docs/spark/VIDEO_PLAN.md) (full plan with pictures and timings).

Final upload: your own YouTube channel, **Unlisted**, landscape, at most 6:30. Then send the link so the poster QR can be updated (`poster/links.json` → `spark_video`).
