# SPARK 2026 voice-over script

Read-aloud version of [VIDEO_PLAN.md](VIDEO_PLAN.md). Only Danish's spoken lines, in order. Pictures and timings are in the plan.

**How to record**
- Scene 1 is the only **face-on-camera** clip (landscape, 1080p). Everything else is **audio only**.
- Record one scene per file, 2 takes each. Name files by scene and take: `vo_03_take1.m4a`, `vo_03_take2.m4a`.
- A slash `/` means a short breath pause. Speak slightly slower than normal.
- Put the files in `video/raw/` (see `video/README.md`).

**Numbers in scenes 17, 18, 20 and 21** come from `metrics/spark2026.json` as of 26 Nov 2026. If the data or metrics change, check these lines against the file before recording.
